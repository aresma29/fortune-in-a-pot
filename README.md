# Fortune in a Pot

A single fortune for a potted plant: lean toward the light, grow one perfect leaf, and finally get watered by someone who actually read the tag.

## How it works

Run `python3 main.py`. It reads `entry.txt` from the same directory as the script, strips the trailing newline, prints the fortune, and exits 0. Standard library only.
